# 14 · Windows XP + MSN（2006）
档案：src/scenes/winxp.js ｜ 时间窗 63.0–67.0 s（4 秒）｜ 幕次 ACT XIV

## 画风与技法（真正的 XP 时代）
- 桌面是 Bliss 式的蓝天绿地：渐层 + 云 + 草丘（Luna 蓝 #6ea9e0 到 #b8dcf5）。
- 任务栏（下缘）是蓝色渐层玻璃条，橘色快速启动列上一排方块图示。
- 视窗是 Luna 玻璃质：蓝色渐层标题列、圆角、阴影、白色内容区。
- MSN 聊天视窗（2006 风格）：蓝绿渐层、圆形联络人头像剪影、表情符号。
- 对话泡泡小图，2006 年那种过饱和蓝、渐层过度、细节杂乱。

## 构图
- 背景：Bliss 桌面（蓝天、绿丘、几朵卷云）。
- 中景：置中的记事本视窗，标题列写 Bicycle.txt，内容逐行打字。
- 中下：MSN 聊天视窗，两个对话泡泡正在互动，其中一个头像是鹈鹕。
- 主体：鹈鹕骑自行车半透明叠在桌面上（像桌面贴图），或骑在聊天视窗标题列上。
- 头像里的两个圆形剪影角色。

## HUD
- 年份：2006，字体 Tahoma（XP 预设字型），颜色 #ffffff（压在蓝色上），kicker“ACT XIV · DESKTOP”。
- 右下标签卡：底 #ffffff，字 #1b3b6f，边框 #ff9c1a；卡要有 XP 视窗的蓝标题列。

## 技术注意
- 一定要用渐层（K.gradTex）做 Luna 玻璃质感，这是 XP 的辨识度来源。
- 视窗阴影用 K.alpha 的深色矩形错位堆叠。
- 文字用 Tahoma；中文用 Microsoft YaHei。
