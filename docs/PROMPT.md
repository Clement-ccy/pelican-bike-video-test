# 提示词 · 从零复现本片

> 这是把整部影片的需求压缩成一次给足的版本。实际制作经过两轮迭代——先做了 17 幕硬切的初版，再推翻改成连续长卷——这里直接给出收敛后的结论。照这份提示词做，可以从零得到同一部片子。

---

请用 p5.js 2.x + p5.brush 2.x（WEBGL 画布）做一支 82 秒、1920×1080、24 fps 的程式生成影片《鹈鹕测试》The Pelican Test。

所有画面都由 JavaScript 逐帧画出（纯函式 `renderAt(t)`，Puppeteer 逐帧截图 → ffmpeg 合成），不可使用任何外部图片／影片素材。

## 概念

人类自古以来就一直在画「鹈鹕骑自行车」——早在自行车被发明之前。一只白鹈鹕骑着车，从四万年前的洞窟一路骑到 2025 年的短视频；每穿过一道接缝，它就被重新画成那个年代的画法。

语气：一本正经的博物馆／纪录片冷面笑话——画得越正经越好笑。不要线稿式的「差不多」，每个年代都要用该年代真正的画风与技法重现。

## 结构：一卷长卷，不剪切

全片是**一卷连续的时光长卷**，从头到尾一次也不切换镜头：

- 17 张画心横向相接：序（题签）+ 15 个年代 + 后记（跋），每张 1920×1080，世界宽 17 × 1920 = 32640 px。
- 镜头一直向右卷，`camX(t)` 从第 1 张画心中心走到第 17 张画心中心；每张画心中央最慢、接缝处最快：`roll(u) = u − (A/2π)·sin(2πu)`，A ≈ 0.62。
- 画心之间是一条装裱接缝：左侧渐暗 + 一道金色细线。
- 鹈鹕固定在画面 x = 742 处踩车，世界从它脚下流过。

**接缝就是蒙版**（全片唯一机关）：鹈鹕属于哪一代，取决于车轮底下压着的是哪张画心。接缝扫过它时（第一次 t ≈ 3.8 s），上一代与这一代的画法分别画进两张 1024×768 图层，各用 `destination-in` 沿接缝的局部 x 切一刀，再叠起来——左边还是石墨，右边已经是红赭。

## 画法与画心必须分离

- `src/scenes/<id>.js` 画画心：这个年代的一张画，含背景、配角、器物、文字。
- `src/skins/<id>.js` 画这只鹈鹕：同一副骨架（鸟 + 车），只是换成这个年代的画法。
- 画心不许自己再画一只骑车的鹈鹕（刻意的「画中的鹈鹕」除外），否则屏幕上会出现两只鸟。
- 画法契约见 `SKINS.md`：注册成 `R.def('<id>', function(g, o){...})`，g 是已经平移到 (400,620)、按 o.s 缩放好的 1024×768 图层；坐标以落地处为 (0,0)，自行车 x −217..217、y −184..0，轮心 (−125,−92)／(125,−92) 半径 92。必须确定（只用 o.t 与固定种子），不许写字，不许画背景；一帧要画两遍，单次 < 25 ms。

## HUD

- 左上：年代（字型与配色随该年代变）。
- 右下：博物馆馆藏标签卡——藏品名、材质、尺寸、编号，加一句冷面笑话。笑话只放在卡上。
- 底部：一条长卷进度尺。
- 三者画在同一个 2D 图层上整体淡入淡出：接缝经过画面中央时淡掉，因为那时没有「一幅画」可以标注。

## 声音

全部程序合成（`tools/audio.py`，numpy），没有任何采样素材：每 2 秒一句，用「该年代的乐器」演奏同一个两音动机；每个接缝一声低鼓 + 一层 whoosh + 一点轻响；底下铺一条 drone；结尾在 73 秒起一个解决和弦。

## 做法（照这个顺序，不要一次全写）

1. 先写共用套件 `src/kit.js`（笔刷、排线、调色、2D 文字图层、framebuffer 烘焙、鹈鹕／自行车骨架）与 `src/beat.js`，再写 `src/scroll.js`（镜头、画心烘焙、接缝）、`src/rider.js`（蒙版）、`src/hud.js`。
2. 写 `STYLE.md`（全片美术规格）与 15 份各年代美术简报（画风、色票、构图、HUD 留白、馆藏卡文案）。
3. 先用 `tools/shot.mjs` 单帧验证套件，再往下。
4. 平行派 15 个子代理，每个只负责一个 `src/scenes/<id>.js` 与一个 `src/skins/<id>.js`；要求每轮「渲染 PNG → 看图 → 改」至少 3 轮。
5. 主代理逐幕看接触表验收，补序与后记，最后渲染全片 → 合成 mp4（H.264 CRF 17 + AAC 48 kHz）。

## 验收标准

- 每一帧都是程序画出来的，仓库里没有任何图片或影片素材。
- 长卷里找不到硬切：任意两帧之间只有镜头位移。
- 接缝扫过鹈鹕的那 0.3 秒内，鸟身上能同时看到两种画法。
- 每个年代一眼能认出技法（洞穴的红赭与手掌印、陶瓶的黑像剪影、木版的套色、网点的印刷错位、像素的抖动……），不是色块。
- 馆藏卡上的笑话正经到好笑；画面上不出现任何解释性文字。
